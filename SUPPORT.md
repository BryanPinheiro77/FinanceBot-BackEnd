# Suporte

O FinanceBot é um projeto open source em estágio inicial.

## Onde pedir ajuda

- consulte primeiro o [README](README.md) e o [índice da documentação](docs/README.md);
- use issues para bugs reproduzíveis e propostas de melhoria;
- use pull requests para alterações de código ou documentação;
- use o reporte privado descrito em [SECURITY.md](SECURITY.md) para vulnerabilidades.

Não publique tokens, senhas, dumps, mensagens reais do Telegram ou dados financeiros em issues, discussões ou pull requests.

## Serviço hospedado

Este repositório documenta a execução self-hosted. Um eventual serviço hospedado terá termos, suporte, disponibilidade e política de privacidade próprios; o código aberto não representa uma promessa de serviço gerenciado.

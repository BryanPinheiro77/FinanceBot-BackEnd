# Skills do projeto

Este diretório contém as skills compartilhadas pelo AIIAHub e selecionadas para
o FinanceBot. Elas orientam agentes de desenvolvimento, revisão, testes,
segurança, banco de dados, observabilidade e operação.

As skills não substituem as regras de [`AGENTS.md`](../AGENTS.md). Em caso de
conflito, as regras do repositório e as instruções do mantenedor prevalecem.

Consulte [`docs/ai-skills.md`](../docs/ai-skills.md) para o catálogo e o critério
de seleção.

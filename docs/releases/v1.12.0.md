# v1.12.0 — Dashboard mensal

Publicação coordenada da [issue #164](https://github.com/BryanPinheiro77/FinanceBot-BackEnd/issues/164).
Publicação coordenada realizada em 05/11/2026 (UTC), com a API antes do frontend.
[Release no GitHub](https://github.com/BryanPinheiro77/FinanceBot-BackEnd/releases/tag/v1.12.0).

## Novidades

- Resumo mensal autenticado da API com receitas, despesas, resultado, série de todos
  os dias do mês e despesas por categoria. Valores calculados com BigDecimal em
  consulta agregada limitada ao usuário autenticado.
- Dashboard web com seletor de mês, cards e gráficos em reais, tabela acessível por
  teclado, temas claro/escuro e layout para celular/desktop.
- Estados de carregamento, vazio, erro com nova tentativa e sessão expirada;
  respostas antigas e dados de outra identidade não permanecem na tela.

Renda cadastrada é referência separada. O resultado mensal não representa saldo
bancário ou projeção. Parcelas entram pela data de cada lançamento; recorrências
não materializadas não são contabilizadas. [Contrato](../dashboard.md).

## Compatibilidade e operação

- Publicar a API antes do frontend: a API antiga não fornece o novo endpoint.
- Sem migrations, novos secrets ou alterações de configuração/autenticação.
  Contratos existentes da API e do bot são preservados.
- Frontend mantido em repositório próprio; demais CRUDs e conclusão da #122
  permanecem fora desta publicação.
- Backup contínuo (#220) e operação self-hosted (#219/#221) continuam pendentes.
  Esta entrega não ativa backup, retenção ou manutenção no host.
- Auditoria npm pré-publicação em 05/11/2026: nove avisos moderados, nenhum alto
  ou crítico. Dependências não foram alteradas nesta entrega.
- Rollback continua exigindo decisão e autorização próprias conforme o
  [procedimento operacional](../deployment.md#rollback-operacional); preservar os
  SHAs anteriores saudáveis. Voltar o frontend pode remover o dashboard; a mudança
  da API é aditiva e não exige reversão de schema.

## Validação local

- `./mvnw clean verify`: 573 testes da API aprovados, sem falhas, erros ou skips;
  inclui 13 testes do resumo com JWT real, isolamento, calendário e centavos.
  PostgreSQL, Redis e RabbitMQ dos testes existentes executaram isolados via Colima.
- Frontend: 22 testes unitários, 18 testes de dashboard e 4 de sessão aprovados;
  typecheck, build, lint dos arquivos alterados e whitespace aprovados.
- Capturas antes/depois com fixtures em `FinanceBot-FrontEnd/docs/evidence/issue-164`.
  Testes de navegador usaram Chromium; não há alegação de testes Safari/Firefox
  nem de auditoria WCAG completa.
- SonarQube não foi executado nesta sessão.

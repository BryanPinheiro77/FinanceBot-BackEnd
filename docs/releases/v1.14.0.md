# v1.14.0 — CRUD web de transações

Preparação autorizada em 05/11/2026 (UTC). A publicação depende dos checks e do
deploy; as notas da release GitHub registrarão os SHAs exatos e os resultados.

A #167 entrega consulta, criação, edição e exclusão unitária de transações no
repositório FinanceBot-FrontEnd, com filtros por período, tipo, conta e categoria,
paginação e confirmação de exclusão. Dinheiro mantém os centavos no transporte
JSON; edição preserva origem Telegram e parcelas afetam somente o item selecionado.

Criação usa chave de idempotência. Respostas incertas permitem reenvio conservador
ou reconciliação; exclusões incertas exigem consultar a lista antes de nova ação.
A main com sessões revogáveis v1.13.0 foi integrada e validada, incluindo criação
após renovação sem mudar corpo ou chave.

## Operação

A API já oferece o contrato necessário; este repositório recebe documentação e
registros da versão. Sem mudanças em Java, migrations, dependências ou variáveis.
A integração Git publica o frontend na Vercel após merge. O backend mantém seu
workflow existente; promover a documentação também o aciona.

## Evidências

- 73 testes unitários/proxy, 36 cenários de transações, 18 de dashboard e 8 de sessão.
- Landing: 41 aprovados e quatro skips preexistentes. Typecheck, build e lint aprovados.
- npm audit: nove moderate existentes, zero high/critical. Nenhuma dependência alterada.
- Fixtures locais; sem criar contas/transações em produção. Sem validação Safari/Firefox.
- Contrato: [Transações web](../frontend-transactions.md).
- Telas e capturas ficam na documentação do repositório frontend.

## Limites

CRUDs completos de contas/categorias, criação/edição de grupos de parcelas e
recorrências ficam fora da #167. Sem ETag/controle otimista de edições simultâneas.
Backup contínuo segue pendente na #220; esta entrega não altera o banco.

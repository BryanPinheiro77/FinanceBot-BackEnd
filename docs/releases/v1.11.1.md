# Publicação v1.11.1

Release publicada em 25/10/2026 (UTC), depois do CI/deploy da API e publicação/validação
coordenada do frontend. [Release no GitHub](https://github.com/BryanPinheiro77/FinanceBot-BackEnd/releases/tag/v1.11.1).

## Segurança da sessão web

- Frontend publicado usa cookie host-only `HttpOnly`, `Secure` e `SameSite=Lax`; o JWT sai do JSON de login/cadastro e do Web Storage. O acesso à API passa pela camada de servidor do frontend, com proteção CSRF e allowlist de endpoints.
- Declaração HMAC exclusiva preserva cotas de login/cadastro por IP. O JWT da API continua com HMAC/Bearer; nenhuma chave JWT foi compartilhada com o frontend nem rotacionada nesta entrega.
- Dependências vulneráveis do frontend atualizadas; `npm audit` retornou zero avisos no preflight e CI. Os 13 erros anteriores de TypeScript foram corrigidos, com auditoria e typecheck adicionados ao CI.

## Operação e documentação

- Runbook de rotina, playbook de incidentes e correções nos procedimentos de backup/rollback.
- Ferramentas opt-in de backup externo com Restic, restore isolado e retenção simulada por padrão. **Não foi ativado backup contínuo nem exclusão automática**: a #220 aguarda destino externo e comprovação operacional.
- Backup pontual cifrado criado antes da publicação, cópia fora do host conferida e restauração PostgreSQL isolada aprovada. Chaveiro recuperado e contagens comparadas contra o mesmo snapshot; nenhuma restauração sobre produção.

## Compatibilidade

- Sem migration nova desde v1.11.0; schema V17 preservado. API/bot mantêm contratos existentes.
- Usuários web precisam entrar novamente após o descarte do token legado. Logout remove o cookie, sem revogação de cópias já roubadas do JWT; não há refresh token nesta etapa.
- Isolamento/manutenção do host (#219/#221), backup contínuo (#220), campos pesquisáveis (#186), dashboard completo e monorepo permanecem frentes próprias.

## Validação realizada

- API: 560 testes; bot, imagens e ferramentas de backup validados no CI. [CI da main](https://github.com/BryanPinheiro77/FinanceBot-BackEnd/actions/runs/40152019990), [deploy](https://github.com/BryanPinheiro77/FinanceBot-BackEnd/actions/runs/40152020001).
- Web: 21 testes, 4 smokes de sessão, 41 testes de landing aprovados e 4 skips existentes. Auditoria, typecheck, build e testes também aprovados no [CI da main do frontend](https://github.com/BryanPinheiro77/FinanceBot-FrontEnd/actions/runs/40152252045).
- 171 pares Maven de runtime consultados no OSV em 25/10/2026, sem avisos ou paginação. Resultados são limitados à base consultada; não incluem inventário de vulnerabilidades do sistema operacional.
- Produção: SHA da API conferido, API/bot saudáveis e sem root, portas HTTP em loopback e origem HTTPS acessível. Duas declarações sintéticas comprovaram contadores independentes por IP, sem criar usuários.
- No domínio web publicado, conta exclusiva de teste validou cadastro/login, cookie protegido e inacessível a JavaScript, ausência de JWT no JSON/Web Storage, reload, logout, guard de rota, CSRF e bloqueio de endpoint interno. Nenhuma transação financeira criada.
